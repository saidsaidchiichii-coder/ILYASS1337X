# Manus Clone

استنساخ دقيق لواجهة منصة Manus AI.

## الميزات

- تصميم واجهة مستخدم حديث وسلس
- شريط جانبي قابل للتفاعل
- منطقة محتوى مركزية
- أزرار إجراءات سريعة
- بطاقة معلومات في الأسفل
- تصميم متجاوب (Responsive)

## البدء السريع

```bash
# تثبيت المتطلبات
npm install

# تشغيل الخادم المحلي
npm start

# أو
npm run serve
```

ثم افتح المتصفح على `http://localhost:8080`

## البنية

```
├── index.html          # الملف الرئيسي
├── package.json        # معلومات المشروع
└── README.md          # هذا الملف
```

## التكنولوجيا المستخدمة

- HTML5
- CSS3 (مع متغيرات CSS)
- JavaScript Vanilla

## المتطلبات

- متصفح حديث يدعم CSS Grid و Flexbox
- Node.js (اختياري، للخادم المحلي)
